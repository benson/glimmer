# glimmer

A loose tldraw-powered canvas for sites, sounds, images, and thoughts that feel worth keeping.

Live at <https://bensonperry.com/glimmer/>.

Run it locally:

```powershell
cd C:\Users\benso\Projects\glimmer
npm install
npm run dev
```

Then open <http://127.0.0.1:4173>. The app stores things added in the browser locally. Things captured through the installed `glimmer` Codex skill live in `data/things.json` and are published by GitHub Pages.

The canvas is pinned to tldraw 3.15.3, whose production terms allow this non-commercial personal project without the license-key enforcement introduced in tldraw 4.0.
