# glimmer

A loose, draggable canvas for sites, sounds, images, and thoughts that feel worth keeping.

Run it locally:

```powershell
cd C:\Users\benso\Projects\glimmer
npm run serve
```

Then open <http://127.0.0.1:4173>. The app stores things added in the browser locally and can export/import a portable JSON copy. Things captured through Codex live in `data/things.json`.
